АСО-Контроль API (учебная версия) (1.0.0)

Download OpenAPI specification:

Упрощённый API сервиса контроля аварийно-спасательного оборудования (АСО) воздушных судов.

Правила:

  • Все запросы и ответы — JSON, поля в camelCase.
  • Авторизация: заголовок Authorization: Bearer <token> (кроме /auth/login и /health).
  • Роли: inspector и admin. Админ может всё, что инспектор, плюс создание и изменение данных. Эндпоинты только для админа помечены (admin).
  • Время — строки ISO 8601 в UTC, даты — YYYY-MM-DD.
  • Ошибки: {"error": {"code": "not_found", "message": "..."}}.
